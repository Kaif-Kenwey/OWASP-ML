IsolationForest Anomaly

200 trees, contamination=0.1 — flags statistically unusual alerts.

Hybrid Score

0.6 × classifier + 0.3 × anomaly + 0.1 × static risk weight. Not a probability.

Academic Honesty — Limitations

{{ metrics.disclaimer if metrics else '' }} Evaluation is based on available scanner-labelled data and should not be interpreted as real-world generalization accuracy. The classifier learns the scanner's risk labels, not independent ground truth; mis-ratings in the scanner propagate to the model. The dataset is a single scan of one deliberately vulnerable test site. Add genuinely new labeled scans (targets you are authorized to test) under data/sample/ and re-run to broaden the evidence base.
